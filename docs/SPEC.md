# 生鲜陈列柜除霜排窗业务规格

## 输入与时点

`day` 从演练档案起始日计数，`arrived` 表示入账日，`clock` 以 15 分钟为一格。测量在发生日之后一日内到达才可进入时点样本，超过窗口的补录留在隔离证据。跨日结果通过 `available` 回读，训练使用冻结日前已确认的最后一份回执。

业务组包括商场负一层、社区小站、街边旗舰、仓卖一体。同一 `case_id` 的同版本异值记录整笔隔离，重复记录只计一笔。

| 信号源 | 含义 | 接受范围 |
| --- | --- | --- |
| `dew_point` | 露点 ℃ | 3 至 24 |
| `door_minutes` | 开柜时长 min | 0 至 54 |
| `frost_mm` | 霜层厚度 mm | 0 至 22 |
| `cabinet_kw` | 额定功率 kW | 1 至 9 |
| `occupancy` | 近一小时客流 | 4 至 95 |
| `idle_window` | 非销售窗口 min | 0 至 115 |
| `pallet` | 冷藏存货占比 % | 10 至 100 |

## 计算与裁决

使用近邻条件分位数，目标单位为 min。数据冻结以 `as_of` 为锚点，选择截至第 `as_of-64` 日的历史，随后依次保留校准段、回放段和待裁决段。
训练样本的中位数与 MAD 用于共享缩放。组内样本数足够时，用组内中位数补齐非关键测量。以下特征按同一名次供回放和推理。

| 派生特征 | 计算 |
| --- | --- |
| `frost_load` | `frost_mm / max(cabinet_kw, 1)` |
| `hygro_open` | `dew_point * door_minutes / 1200` |
| `power_margin` | `cabinet_kw / 9` |
| `stock_fill` | `pallet / 100` |

关键测量不全、回放门限失败或组分布出现明显变化时进入人工复核。业务锁包括销售窗口或存货保护期。最终分派受门店除霜工位总额和组内上限约束，使用额度守恒回读工作单。
